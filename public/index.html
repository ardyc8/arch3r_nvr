📦 Install Addon Baru

Masukkan URL sumber Addon atau URL repositori GitHub. Sistem akan mengunduh dan melakukan instalasi otomatis ke direktori /addons.

Syarat & Ketentuan Pembuatan Addon:
  • Repositori harus memiliki file manifest.json di root directory.
  • Untuk addon berbasis Python, harus menyediakan requirements.txt.
  • Script utama (Node.js/Python) akan otomatis diregistrasikan dan dijalankan oleh PM2 Ecosystem.
  • Pastikan addon kompatibel dengan arsitektur arm64 (Linux Armbian).
